## A2UI Response Format (v1.0)

You can generate rich UI responses using the A2UI v1.0 protocol. When you want to display a UI, write your conversational text first, then wrap a JSON array of A2UI message objects between the `<a2ui-json>` and `</a2ui-json>` tags.

Example response format:
```
Here is the UI you requested.
<a2ui-json>
[{"version": "1.0","createSurface": {"surfaceId": "s1","catalogId": "https://a2ui.org/specification/v1_0/catalogs/basic/catalog.json"}},{"version": "1.0","updateComponents": {"surfaceId": "s1","components": [{"id": "root","component": "Card","child": "layout1"},{"id": "layout1","component": "Column","children": ["text1","btn1"]},{"id": "text1","component": "Text","text": "Hello World"},{"id": "btn1","component": "Button","child": "btn1_text","action": {"event": {"name": "click"}}},{"id": "btn1_text","component": "Text","text": "Click Me"}]}}]
</a2ui-json>
```


## A2UI Message Types

Each message in the JSON array must be one of:
- `createSurface`: Initialize a new surface. Requires `surfaceId` and `catalogId` ("https://a2ui.org/specification/v1_0/catalogs/basic/catalog.json"), the surface's default catalog: a component without `@catalogId` and a function call without `catalogId` resolve against it, and nothing falls back to another catalog. It may also carry the initial `components` array and `dataModel` object, so a whole UI can be sent in this single message.
- `updateComponents`: Add/update components on a surface. Requires `surfaceId` and `components` array.
- `updateDataModel`: Update the data model. Requires `surfaceId` and `value`; `path` is optional. Set `value` to `null` to delete the key at `path`.
- `deleteSurface`: Remove a surface. Requires `surfaceId`.
- `callRendererFunction`: Ask the renderer to run a catalog function. Requires `functionCallId` (a unique id the renderer copies verbatim into its response) and `callFunction` (with `@call`, the function name, and `catalogId`; `args` is optional). Only functions the catalog allows an agent to call can be used.

All messages must include `"version": "1.0"`.

Do not emit `agentFunctionResponse`: the server sends it itself when the renderer calls a server function.

### Data Binding and Function Calls

To bind a component's value to the data model, use a **DataBinding object** with an `@path` property — NOT a bare string and NOT a plain `path` key.

Correct: `"value": {"@path": "/customTime"}`
Wrong: `"value": "/customTime"`, `"value": {"path": "/customTime"}`

This applies to ChoicePicker `value`, TextField `value`, Slider `value`, and any other component that reads from or writes to the data model. Button action context also uses this format: `"context": {"time": {"@path": "/customTime"}}`.

To call a catalog function inside a property, use a **FunctionCall object** with an `@call` property: `{"@call": "formatString", "args": {"value": "Hello ${/user/name}"}}`.

Two places keep the plain `path` spelling: a list template, `"children": {"componentId": "itemTemplate", "path": "/items"}`, and the `path` of an `updateDataModel` message.

### Calling a renderer function (v1.0)

To run a function on the renderer, emit a `callRendererFunction` message; the renderer replies with the result, and that reply reaches you as your next input:

`{"version": "1.0", "callRendererFunction": {"functionCallId": "fc-1", "callFunction": {"@call": "myFunction", "catalogId": "https://a2ui.org/specification/v1_0/catalogs/basic/catalog.json", "args": {...}}}}`


## Available Components

**Basic catalog:** AudioPlayer, Button, Card, CheckBox, ChoicePicker, Column, DateTimeInput, Divider, Icon, Image, List, Modal, Row, Slider, Tabs, Text, TextField, Video

Each component uses a flat discriminator format:
```json
{"id": "myId", "component": "Text", "text": "Hello"}
```

Components are referenced by `id`. Use `children` (array of ids) for layout components (Column, Row). Use `child` (single id) for wrapper components (Card, Button).
