Model runs and standalone work share the task lifecycle: `#!python TaskStarted`,
optional `#!python TaskProgress`, and one terminal event — `#!python TaskCompleted`,
`#!python TaskFailed`, `#!python TaskExpired`, or `#!python TaskCancelled`.
Observers, network mirrors, and UIs consume the same events in each case.

## Model Runs

Pass `#!python capability` or `#!python ttl_seconds` to enable lifecycle events
for an agent invocation:

```python linenums="1"
from ag2 import Agent
from ag2.config import OpenAIResponsesConfig

agent = Agent("researcher", config=OpenAIResponsesConfig(model="gpt-5"))

reply = await agent.ask(
    "Research deployment patterns",
    capability="research",
    ttl_seconds=60,
)
```

`#!python capability` tags the work for network observations.
`#!python ttl_seconds` carries an absolute expiry deadline on `#!python TaskStarted`;
an external observer owns expiry. It does not set a local execution timeout.
Omitting both options leaves ordinary runs without task lifecycle events.

The observable form accepts the same options:

```python linenums="1"
from ag2 import Agent
from ag2.config import OpenAIResponsesConfig
from ag2.events import TaskCompleted, TaskStarted

agent = Agent("researcher", config=OpenAIResponsesConfig(model="gpt-5"))

def show_task(event):
    print(type(event).__name__, event.task_id)

async with agent.run("Research deployment patterns", capability="research") as run:
    run.stream.where(TaskStarted | TaskCompleted).subscribe(show_task, sync_to_thread=False)
    reply = await run.result()
```

Entering `#!python run` opens the scope. `#!python TaskStarted` is emitted when
`#!python start()` or `#!python result()` drives it; leaving an undriven run emits
no task events. Repeated `#!python result()` calls share one invocation and
one lifecycle. The terminal is emitted after middleware and observer cleanup
when the run scope closes. `#!python ask()` completes that cleanup before it
returns. Subscribe directly to the stream to observe the terminal after
run-scoped observers have been released.

A model or tool exception produces `#!python TaskFailed` and propagates to the
caller. Cancelling the turn or leaving a running scope produces
`#!python TaskCancelled` after running tools and descendants have settled.
Setup errors produce a start/failure pair even if the model never runs.
Cleanup errors produce a failure terminal and propagate to the caller;
cleanup cancellation produces `#!python TaskCancelled`.

Waiting for a shared stream's turn lock happens before the run scope opens.
Cancelling an ordinary invocation during that wait emits no task events.
A delegation also reports a rejected attempt to its parent as a start/cancellation
pair, using the same lifecycle transitions without entering the busy stream.

`#!python AgentReply.ask()`, `#!python AgentReply.run()`, and `#!python Agent.resume()`
accept the same options. Each continuation gets a fresh task identity when
opted in; capability and TTL are supplied per invocation. Recovery of model
work uses the recorded trajectory and `#!python resume()`.

Delegations through `#!python Agent.as_tool()` use this lifecycle automatically,
with the delegation's task ID and parent tool-call ID. Ancestors receive the
same events with their source path, without duplicate starts or terminals.
See [Subagents](/docs/user-guide/subagents).

## Standalone Work

Construct `#!python Task` directly for arbitrary coroutines outside the model
loop. Tasks are owner-driven; the framework does not assign or schedule them.

### When to Use a Standalone Task

Use a Task whenever a unit of work has a beginning, an end, and observable progress that you want to surface beyond your own function's return value:

- **Long-running pipelines** where downstream consumers want progress checkpoints.
- **HITL approvals** where a UI needs to know the task is waiting on a human.
- **Test harnesses** that assert a sequence of lifecycle events.

### Standalone Example

```python linenums="1" hl_lines="6"
from ag2 import Agent
from ag2.task import Task, TaskSpec

agent = Agent("indexer")

async with Task(owner_id=agent.name, spec=TaskSpec(title="index documents")) as task:
    await task.progress({"stage": "discover", "files": 12})
    await task.progress({"stage": "index", "indexed": 12})
    await task.complete({"indexed": 12})

print(task.state)        # TaskState.COMPLETED
print(task.metadata.result)  # {'indexed': 12}
```

The `#!python async with` block opens the lifecycle. On clean exit the task auto-completes with `#!python result=None` if you didn't call `#!python complete()` or `#!python fail()` yourself.

## Lifecycle States

```
CREATED -> RUNNING -> COMPLETED   (terminal, success)
                   -> FAILED      (terminal, exception or explicit fail)
                   -> EXPIRED     (terminal, externally observed expiry)
                   -> CANCELLED   (terminal, explicit or coroutine cancellation)
```

| State | Meaning |
|---|---|
| `CREATED` | The Task object exists but `#!python __aenter__` has not run. `#!python task.task_id` and `#!python task.metadata` raise. |
| `RUNNING` | Inside the `#!python async with` block. Progress events allowed. |
| `COMPLETED` | Reached `#!python complete()` or clean block exit. |
| `FAILED` | Reached `#!python fail()` or block exited via exception. |
| `EXPIRED` | An external observer marked the task expired. |
| `CANCELLED` | Reached `cancel()` or the coroutine exited with `asyncio.CancelledError`. |

The terminal states are immutable — once set, further `#!python complete() / fail() / progress()` calls are silent no-ops. The set is exported as `#!python ag2.task.TERMINAL_TASK_STATES`.

## API Reference

### `#!python Task(...)`

```python
from ag2.task import CheckpointStore, Task, TaskSpec

Task(
    owner_id=agent.name,
    spec=TaskSpec(
        title="index documents",
        description="",
        payload={},
        capability=None,
    ),
    context=None,
    ttl_seconds=None,
    checkpoint_store=None,
    resume_from=None,
)
```

| Parameter | Type | Description |
|---|---|---|
| `owner_id` | `str` | Owner identity included in lifecycle events; use `agent.name` for agent-owned work. |
| `spec` | `TaskSpec` | Title, description, payload and optional capability tag. |
| `context` | `ConversationContext \| None` | Events flow on `context.stream`; `TaskInject` resolves to this Task for the duration of the block. If omitted, the Task creates a private `MemoryStream` on entry. |
| `ttl_seconds` | `int \| None` | Sets `metadata.expires_at`; an external observer owns expiry. |
| `checkpoint_store` | `CheckpointStore \| None` | Store for owner-defined checkpoint state. |
| `resume_from` | `str \| None` | Prior task ID whose checkpoint is loaded into `task.resumed_state` on entry. |

Returns an unentered Task. Construction does not start work or emit events.

`TaskSpec` describes the work:

| Field | Type | Default | Description |
|---|---|---|---|
| `title` | `str` | Required | Short objective shown on every event. |
| `description` | `str` | `""` | Longer description. |
| `payload` | `dict[str, Any]` | Fresh `{}` | Owner-defined task data. |
| `capability` | `str \| None` | `None` | Capability name used by network mirrors. |

### `#!python Task` instance methods

| Method | Description |
|---|---|
| `#!python await task.progress(payload)` | Emits `#!python TaskProgress`; merges `payload` into `#!python metadata.progress` and stamps `#!python last_progress_at`. No-op if already terminal. |
| `#!python await task.complete(result=None)` | Terminal. Emits `#!python TaskCompleted`; sets `#!python metadata.result` and `#!python state = COMPLETED`. |
| `#!python await task.fail(error)` | Terminal. Accepts a string (wrapped in `#!python RuntimeError`) or any `#!python BaseException`. Emits `#!python TaskFailed`; sets `#!python state = FAILED`. |
| `#!python await task.cancel(reason="")` | Terminal. Emits `#!python TaskCancelled`; sets `state = CANCELLED`. |
| `#!python await task.checkpoint(state)` | Persists owner-defined recovery state through the configured store. |
| `#!python await task.expire()` | Terminal. Emits `#!python TaskExpired`; sets `#!python state = EXPIRED`. Called by external TTL observers. |

### Properties

| Property | Available before `#!python __aenter__`? |
|---|---|
| `#!python task.state` | Yes — returns `#!python TaskState.CREATED`. |
| `#!python task.task_id` | No — raises `#!python RuntimeError`. |
| `#!python task.metadata` | No — raises `#!python RuntimeError`. |
| `#!python task.context` | No — raises `#!python RuntimeError`. |

## Bound Context vs. Standalone

```python linenums="1" hl_lines="4 6"
from ag2.context import ConversationContext
from ag2.stream import MemoryStream

ctx = ConversationContext(stream=MemoryStream())

async with Task(owner_id=agent.name, spec=TaskSpec(title="with-ctx"), context=ctx) as task:
    ...
```

Passing a `#!python ConversationContext` shares the stream with the rest of your agent's run, so observers and middleware already attached to that stream see the lifecycle events.

Without a context, the Task creates a private stream on entry. Events still fire — but only observers attached to that private stream see them. Useful for one-off background work that doesn't need to surface anywhere.

## Auto-Complete and Auto-Fail

The `#!python async with` block has these guarantees:

- **Clean exit, no terminal call** -> auto `#!python complete(result=None)`.
- **Exception inside the block** -> auto `#!python fail(exc)`, then the exception propagates.
- **Coroutine cancellation** -> auto `#!python cancel("cancelled")`, then cancellation propagates.
- **Already terminal at exit time** -> nothing further happens.

```python linenums="1" hl_lines="3 5"
try:
    async with Task(owner_id=agent.name, spec=TaskSpec(title="flaky")) as task:
        raise ValueError("boom")
except ValueError as exc:
    print(task.state)            # TaskState.FAILED
    print(task.metadata.error)   # 'boom'
```

## Observing the Lifecycle

Subscribe directly on the bound stream to capture every lifecycle event in order.

```python linenums="1" hl_lines="6-9"
from ag2.events import TaskCompleted, TaskProgress, TaskStarted

stream = MemoryStream()
ctx = ConversationContext(stream=stream)

stream.subscribe(
    lambda ev: print(type(ev).__name__, getattr(ev, "payload", "")),
    sync_to_thread=False,
)

async with Task(owner_id=agent.name, spec=TaskSpec(title="watched"), context=ctx) as task:
    await task.progress({"step": "fetch"})
    await task.complete({"ok": True})
```

!!! note
    `#!python TaskProgress` is marked transient — it is delivered live to subscribers but **not** persisted to the stream's storage. Subscribe before the events fire to capture them. `#!python TaskStarted`, `#!python TaskCompleted`, `#!python TaskFailed`, and `#!python TaskExpired` are persisted normally.

## Reading the Active Task with `#!python TaskInject`

Model runs do not inject a standalone Task or replace one supplied by an enclosing block. Use context variables for model-run state.

Inside an `#!python async with Task(...)` block, the framework stamps the active Task into `#!python context.dependencies["ag2.task"]`. Two ways to read it:

### Direct access

```python linenums="1"
async with Task(owner_id=agent.name, spec=TaskSpec(title="work"), context=ctx) as task:
    active = ctx.dependencies["ag2.task"]
    assert active is task
```

### `#!python TaskInject` annotation

`#!python TaskInject` is a fast_depends-resolvable annotation that injects the active Task into any function the dependency-injection machinery resolves — most usefully a `#!python @tool` body.

```python linenums="1" hl_lines="2 5"
from ag2 import tool
from ag2.task import TaskInject

@tool
async def report(message: str, task: TaskInject) -> str:
    if task is None:
        return "no active task"
    await task.progress({"tool_message": message})
    return f"reported on task {task.task_id}"
```

The injection has `#!python default=None`, so always treat `task` as possibly `#!python None` and null-check before use.

## TTL and Expiry

Setting `#!python ttl_seconds=N` populates `#!python metadata.expires_at` but **does not** start a timer. The Task primitive itself never self-expires — that's by design, so a standalone Task with no observer doesn't spawn a background task. Instead, an external observer (e.g. a network hub's TTL sweeper, a periodic watch) checks `#!python expires_at` and calls `#!python task.expire()` when due.

For self-contained TTL behaviour, wire up a sweeper in your application:

```python linenums="1" hl_lines="3 4"
async def sweep(task: Task, deadline: datetime) -> None:
    while task.state == TaskState.RUNNING:
        if datetime.now(timezone.utc) >= deadline:
            await task.expire()
            return
        await asyncio.sleep(1.0)
```

## Checkpoint and Recovery

Pass a `#!python checkpoint_store` to persist owner-defined state with
`#!python await task.checkpoint(state)`. To continue that work, construct a new
Task with the same store and `#!python resume_from` set to the prior task ID.
On entry, `#!python task.resumed_state` contains the saved state, or
`#!python None` if no checkpoint is available. The application decides how to
continue from that state.

```python
from ag2.task import Task, TaskSpec

async with Task(
    owner_id=agent.name,
    spec=TaskSpec(title="index documents", capability="indexing"),
    context=ctx,
    checkpoint_store=store,
    resume_from=prior_task_id,
) as task:
    next_document = (task.resumed_state or {}).get("next_document", 0)
    await task.progress({"next_document": next_document})
    # Process the next batch, then save where to continue.
    await task.checkpoint({"next_document": next_document + 12})
```

Without a checkpoint store, `#!python checkpoint()` is a no-op and
`#!python resumed_state` is `#!python None`.

## TaskSpec and TaskMetadata

Two small dataclasses surface around a Task:

- `#!python TaskSpec` — what the task is doing: `title`, `description`, `payload`, optional `capability`. Passed to `#!python Task(spec=...)`.
- `#!python TaskMetadata` — mutable lifecycle record updated on each transition: `task_id`, `owner_id`, `spec`, `state`, ISO-8601 timestamps, `progress`, `result`, `error`, optional `channel_id`.

```python linenums="1"
async with Task(
    owner_id=agent.name,
    spec=TaskSpec(title="survey", description="probe upstream", payload={"region": "us"}),
) as task:
    print(task.metadata.spec.title)        # 'survey'
    print(task.metadata.spec.payload)      # {'region': 'us'}
    print(task.metadata.owner_id)          # 'researcher'
    print(task.metadata.started_at)        # ISO 8601 string
```
