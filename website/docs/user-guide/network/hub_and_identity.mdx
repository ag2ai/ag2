The hub is the network's single source of truth: registry, audit log, channel table, write-ahead logs, expectation evaluators, sweepers. Every send, observation, and rule check goes through it.

This page covers the registry-side primitives — what you stand up before any agent connects.

## Hub.open

```python linenums="1"
from ag2.knowledge import MemoryKnowledgeStore
from ag2.network import Hub

hub = await Hub.open(
    MemoryKnowledgeStore(),
    ttl_sweep_interval=30.0,        # default: 30s
    expectation_sweep_interval=10.0,# default: 10s
    invite_ack_timeout=30.0,        # default: 30s
)
```

| Parameter | Type | Description |
|---|---|---|
| `store` | `KnowledgeStore` | Persistent backing for the audit log, registry, and WAL. `MemoryKnowledgeStore` for in-process; `DiskKnowledgeStore(path)` for durability across restarts. |
| `auth` | `AuthRegistry` \| `None` | Authentication adapters. Defaults to `AuthRegistry.default()` (which has `NoAuth` only). |
| `clock` | `Callable[[], str]` \| `None` | ISO-8601 clock. Tests override with a `MockClock`; production uses the default UTC clock. |
| `ttl_sweep_interval` | `float` | How often the TTL sweeper walks active channels. Set to `0` to disable. |
| `expectation_sweep_interval` | `float` | How often the expectation sweeper checks declared expectations. Set to `0` to disable. |
| `invite_ack_timeout` | `float` | Per-channel ack window before the hub auto-closes. |

`#!python Hub.open(...)` is the factory; the constructor `#!python Hub(...)` exists but doesn't start sweepers. Use `#!python open()` unless you have a reason not to.

!!! note
    All side effects (sweeper tasks, store initialisation) happen inside `#!python Hub.open()`, never in the constructor — this matches the AGENTS.md "no side effects in `__init__`" rule. The same pattern applies throughout the package.

## Identity Model

Three small dataclasses describe an agent on the network:

```python linenums="1"
from ag2.network import Passport, Resume, ResumeExample

passport = Passport(
    name="alice",
    owner="acme",
    model="claude-sonnet-5",
)

resume = Resume(
    claimed_capabilities=["analysis", "policy"],
    domains=["finance"],
    summary="Senior policy analyst — scenario synthesis and rebuttal review.",
    examples=[ResumeExample(title="Q3 risk brief", note="…")],
)
```

### Passport — stable identity

| Field | Required | Notes |
|---|---|---|
| `name` | ✓ | Unique within the hub. The human-readable handle. |
| `agent_id` | hub-stamped | Issued by the hub at registration; use this for routing. |
| `owner` | optional | Tenant id for multi-tenant deployments. |
| `model` | optional | Free-form model identifier; surfaces on peer-lookup results when peer discovery ships. |
| `kind` | optional | One of `#!python "agent"`, `#!python "human"`, `#!python "remote_agent"`, or `#!python None`. `#!python None` is the back-compat alias for `#!python "agent"`. `#!python "human"` is set automatically by `#!python hc.register_human(...)`; `#!python "remote_agent"` is reserved for a future federation / A2A bridge. `#!python __post_init__` rejects any other value. Exported as `#!python PassportKind` / `#!python PASSPORT_KINDS`. |
| `created_at` | hub-stamped | ISO-Z timestamp. |

`#!python hub.list_agents(kind=...)` filters the registry by participant kind — `#!python kind="human"` returns only humans, `#!python kind="agent"` returns agents (and matches `#!python kind=None` passports), `#!python kind=None` returns everything. Non-LLM participants are registered via `#!python hc.register_human(...)` — see [HumanClient (HITL)](/docs/user-guide/network/human_client).

### Resume — capability claims and observed track record

| Field | Source | Notes |
|---|---|---|
| `claimed_capabilities` | tenant | Free-form capability strings (e.g. `"research"`, `"summarisation"`). |
| `domains` | tenant | Coarse subject-matter areas. |
| `summary` | tenant | One-line description, indexed for peer lookup. |
| `examples` | tenant | Optional `#!python ResumeExample` records — exemplar past work. |
| `observed` | **hub-mutated** | Per-capability `#!python ObservedStat`: counts of completed/failed/expired tasks plus a `p50_latency_ms`. Updated automatically when an agent runs a capability-tagged `#!python Task(...)` inside a network turn — see [Task Observation](/docs/user-guide/network/task_observation). |
| `last_updated` | hub-stamped | ISO-Z, refreshed on every mutation. |

`#!python Resume` is the agent's network "CV" — both what it claims to do and what the hub has observed it actually doing.

## Rule — per-agent governance

Optional per-agent policy. Pass to `#!python hub.register(agent, passport, resume, rule=...)`.

```python linenums="1"
from ag2.network import Rule, AccessBlock, ChannelTypeAccess, LimitsBlock, RateBlock, InboxBlock

rule = Rule(
    access=AccessBlock(
        outbound_to=["bob", "carol"],   # whitelist who this agent can address
        channel_types=ChannelTypeAccess(
            initiate=["consulting", "discussion"],
            accept=["consulting", "discussion"],
        ),
    ),
    limits=LimitsBlock(
        channel_ttl_default="4h",
        delegation_depth=2,
        rate=RateBlock(per_minute=60),
        inbox=InboxBlock(max_pending=100),
    ),
)
```

| Block | Controls |
|---|---|
| `AccessBlock` | Who this agent can address (`outbound_to`) and who can address it (`inbound_from`); channel-type allowlists (`channel_types`, stored only). |
| `LimitsBlock` | Default TTLs for channels this agent creates; max delegation depth. |
| `RateBlock` | Rate-limit configuration stored under `limits.rate`; not enforced by the in-process hub. |
| `InboxBlock` | Inbound queue cap under `limits.inbox` — protects an agent from being flooded. |

`#!python AccessBlock.channel_types` uses separate allowlists for initiating and accepting channels; like `#!python RateBlock`, it is stored on the rule but not enforced by the in-process hub yet. `#!python RateBlock` and `#!python InboxBlock` belong inside `#!python LimitsBlock`, not directly on `#!python Rule`. Setting `#!python RateBlock.per_minute` stores the configuration; it does not enable throttling in the in-process hub.

When a rule's check fails, the hub raises `#!python AccessDeniedError` (deny by access) or `#!python InboxFull` (queue cap) instead of letting the envelope through.

## Authentication

Authentication decides whether a participant may register under the name in its passport. By default the hub accepts everyone: `#!python Hub.open(store)` uses `#!python AuthRegistry.default()`, which holds only `#!python NoAuth`. That is fine while every agent runs inside your own process, because the hub then holds only agents your code created.

Turn authentication on once other processes can connect to the hub. Over the network, `#!python NoAuth` lets any client act as any agent, so `#!python serve_ws` refuses to bind a hub that still accepts it to a non-loopback address — see [Distributed Networks](/docs/user-guide/network/distributed#authentication).

### How it fits together

Authentication has two halves:

- **The hub** is opened with an `#!python AuthRegistry` — a list of adapters. Each adapter handles one **scheme**, a short string such as `#!python "api_key"`.
- **Each agent** presents a credential in its passport: `#!python Passport(auth=AuthBlock(scheme=..., claim=...))`. The `scheme` names the adapter that should check it; the `claim` is the credential itself, a dict whose shape that adapter defines.

At registration the hub looks up the adapter for `#!python passport.auth.scheme` and calls its `#!python validate(passport, claim)`. If the adapter raises `#!python AuthError`, or no adapter is registered for that scheme, `#!python hub.register(...)` raises `#!python AuthError` and the agent is not registered.

A passport built without `auth=` carries `#!python AuthBlock()`, whose scheme is `#!python "none"` — the scheme `#!python NoAuth` handles. That is why plain registration works on a default hub, and why it is rejected once `#!python NoAuth` is gone.

### API keys

`#!python ApiKeyAuth` is the built-in adapter: each agent name has one secret token. Configure the tokens on the hub, and have each agent send its own token as `#!python {"token": ...}`:

```python linenums="1" hl_lines="7-8 12-15"
import os

from ag2 import Agent
from ag2.knowledge import MemoryKnowledgeStore
from ag2.network import ApiKeyAuth, AuthBlock, AuthRegistry, Hub, Passport

auth = AuthRegistry([ApiKeyAuth(keys={"alice": os.environ["ALICE_API_KEY"]})])
hub = await Hub.open(MemoryKnowledgeStore(), auth=auth)

alice = await hub.register(
    Agent("alice"),
    passport=Passport(
        name="alice",
        auth=AuthBlock(scheme="api_key", claim={"token": os.environ["ALICE_API_KEY"]}),
    ),
)
```

Lines 7–8 are the hub's side: `keys` maps a passport **name** to the token expected for it. Lines 12–15 are the agent's side. Both run in one process here to keep the example short; in a real deployment the agent registers from another process through a `#!python HubClient` and reads its token from its own configuration.

Registration fails with `#!python AuthError` when the token is wrong, when the name has no key, or when the passport has no `api_key` credential at all — for example `#!python await hub.register(Agent("bob"))` on this hub raises `AuthError: unknown auth scheme: 'none'`.

When tokens live in a secret manager or a database, pass an async `resolver` instead of (or in addition to) `keys`. It receives the passport name and returns the expected token, or `#!python None` for an unknown name; `keys` is checked first:

```python linenums="1"
import os

from ag2.network import ApiKeyAuth, AuthRegistry

async def lookup_api_key(name: str) -> str | None:
    # Replace with a call to your secret store.
    return os.environ.get(f"{name.upper()}_API_KEY")

auth = AuthRegistry([ApiKeyAuth(resolver=lookup_api_key)])
```

### Mixing authenticated and open registration

A registry may hold several adapters, and each agent picks one through its passport's scheme. To keep accepting agents without credentials alongside API-key agents, add `#!python NoAuth()`:

```python linenums="1"
from ag2.network import ApiKeyAuth, AuthRegistry, NoAuth

auth = AuthRegistry([NoAuth(), ApiKeyAuth(keys={"alice": "..."})])
```

Note that with `#!python NoAuth` present, any client can still register under any name the API keys don't cover, and `#!python serve_ws` treats the hub as unauthenticated.

### Writing a custom adapter

Write your own adapter when agents already hold credentials from another system — for example, JWTs issued by your identity provider. An adapter is any class with a `scheme` attribute and an async `validate(passport, claim)` method; it satisfies the `#!python AuthAdapter` protocol structurally, with no base class.

This adapter accepts agents that present a JWT signed by your identity provider. It uses [PyJWT](https://pyjwt.readthedocs.io/){.external-link target="_blank"} (`pip install "pyjwt[crypto]"`) to check the signature, expiry and audience:

```python linenums="1" hl_lines="8 24-25"
from typing import Any

import jwt

from ag2.network import AuthError, AuthRegistry, Passport

class JwtAuth:
    scheme = "jwt"

    def __init__(self, public_key: str, audience: str) -> None:
        self._public_key = public_key
        self._audience = audience

    async def validate(self, passport: Passport, claim: dict[str, Any]) -> None:
        try:
            payload = jwt.decode(
                claim.get("token", ""),
                self._public_key,
                algorithms=["RS256"],
                audience=self._audience,
            )
        except jwt.InvalidTokenError as exc:
            raise AuthError(f"invalid token for {passport.name!r}") from exc
        if payload.get("sub") != passport.name:
            raise AuthError(f"token was not issued to {passport.name!r}")

auth = AuthRegistry([JwtAuth(public_key=IDP_PUBLIC_KEY, audience="ag2-hub")])
```

`IDP_PUBLIC_KEY` stands for your identity provider's public key, loaded from configuration. The hub only verifies tokens and never holds a signing secret. Each agent registers with the token it got from the provider:

```python linenums="1"
passport = Passport(name="alice", auth=AuthBlock(scheme="jwt", claim={"token": alice_jwt}))
```

What the example shows, and what any adapter needs to get right:

- **Return `#!python None` to accept, raise `#!python AuthError` to reject.** Turn your library's errors into `#!python AuthError`, as the `#!python except` block does. The message reaches the client, so don't put secrets in it.
- **Tie the credential to the passport.** A valid token proves only that its holder is *somebody*. The `sub` check is what stops Alice's token from registering an agent named `bob`. Whatever your credential identifies (a subject, a tenant, a certificate), compare it to `#!python passport.name` or `#!python passport.owner`.
- **Read the credential from `claim`, not from `#!python passport.auth.claim`.** The hub doesn't store credentials. When a remote agent reconnects with [`attach`](/docs/user-guide/network/distributed#at-least-once-delivery), the hub calls `validate` again with the stored passport, whose claim is empty, and passes the newly sent credential in `claim`. The reconnect must use the scheme the agent registered with.
- **Leave the cryptography to a library.** Verifying signatures, expiry and audience is the library's job. Your adapter maps its result onto the hub's identity.

## Audit Log

Every governance-relevant event the hub processes lands in `#!python hub.audit_log` (an `#!python AuditLog`, which is itself a registered `#!python HubListener`):

```python linenums="1"
records = await hub.audit_log.read_all()
for r in records:
    print(r["kind"], r["at"], r)
```

Audit kinds (re-exported from `#!python ag2.network`):

| Kind | When |
|---|---|
| `#!python AUDIT_KIND_AGENT_REGISTERED` | `#!python hub.register(...)` |
| `#!python AUDIT_KIND_AGENT_UNREGISTERED` | `#!python hc.unregister(...)` |
| `#!python AUDIT_KIND_RESUME_SET` | `#!python hub.set_resume(...)` |
| `#!python AUDIT_KIND_SKILL_SET` | `#!python hub.set_skill(...)` |
| `#!python AUDIT_KIND_RULE_SET` | `#!python hub.set_rule(...)` |
| `#!python AUDIT_KIND_CHANNEL_CREATED` | `#!python alice.open(...)` |
| `#!python AUDIT_KIND_CHANNEL_CLOSED` | adapter close, explicit close, or `auto_close` violation |
| `#!python AUDIT_KIND_CHANNEL_EXPIRED` | TTL sweep |
| `#!python AUDIT_KIND_TASK_TERMINATED` | A task observed via `#!python TaskMirror` reached a terminal state |
| `#!python AUDIT_KIND_EXPECTATION_VIOLATED` | An expectation evaluator's threshold elapsed |
| `#!python AUDIT_KIND_TURN_FAILED` | A notify handler crashed while processing an inbound envelope (channel stays alive — see resilience note below) |

The kind set is **open** — tenants and hub subclasses can write their own kinds via `#!python hub.audit_log.append(record)`. The audit log is the single trail for compliance and debugging — see [Governance, Audit & Observability](/docs/user-guide/network/expectations_and_audit).

## Hub TTL & Sweepers

Two background tasks run as long as the hub is open:

- **TTL sweeper** — walks active channels and expires those past `#!python created_at + ttl`. Default TTL comes from `#!python Rule.limits.channel_ttl_default` or the adapter's manifest.
- **Expectation sweeper** — walks the expectation evaluators registered for each open channel, fires `#!python ViolationHandler`s on threshold breach.

Both are tunable via `#!python ttl_sweep_interval` and `#!python expectation_sweep_interval`. Set to `0` to disable for tests; in those cases call `#!python await hub._ttl_tick()` or `#!python await hub._expectation_tick()` manually for deterministic timing.

### Custom sweepers

Attach your own periodic worker — protocol-specific background work like polling a chat platform's presence list or refreshing an auth token:

```python linenums="1"
async def heartbeat() -> None:
    ...  # runs every 30s

hub.register_sweeper("heartbeat", 30.0, heartbeat)
# later, e.g. on a config reload:
await hub.unregister_sweeper("heartbeat")
```

- `#!python register_sweeper(name, interval_seconds, fn)` is **synchronous** (it only updates bookkeeping). If the hub has already started (`#!python Hub.open(...)` calls `#!python start()` for you), the sweeper begins immediately; if you registered it before `#!python start()`, it begins then.
- `#!python unregister_sweeper(name)` is **async** — it awaits clean cancellation of the running task. Unknown names are a no-op.
- A duplicate `name` raises `#!python ValueError` (call `#!python unregister_sweeper` first to replace); a non-positive interval raises `#!python ValueError`.
- `#!python hub.close()` stops every custom sweeper automatically — you don't need to track them yourself.

## Closing Down

```python
await hub.close()
```

Cancels all sweeper tasks, closes the underlying store, drains pending I/O. Always pair `#!python Hub.open(...)` with `#!python hub.close()` (typically in a `try/finally`).
