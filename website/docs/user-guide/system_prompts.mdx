# Prompt Management

## System Prompts

Agents can be initialized with a static system prompt. You can provide a single string or a list of strings:

```python linenums="1" hl_lines="6 12-15"
from ag2 import Agent

# Single string prompt
agent = Agent(
    "assistant",
    prompt="You are a helpful agent!"
)

# List of strings prompt
agent2 = Agent(
    "assistant2",
    prompt=[
        "You are an expert in Python.",
        "Be concise."
    ]
)
```

## Dynamic Prompts

### On conversation startup

System prompts can be generated dynamically when a conversation starts. This is useful when the prompt depends on external state or initial context. You can achieve this by using the `@my_agent.prompt` decorator or passing a synchronous or asynchronous function.

Dynamic prompt functions support the same powerful execution context capabilities as Agent Tools. For more detailed information on specific context features, see [Dependency Injection](/docs/user-guide/context/inject), [Context Variables](/docs/user-guide/context/variables), and [Human-in-the-loop](/docs/user-guide/context/human_in_the_loop).

Dynamic prompts are evaluated only once at the beginning of the conversation, and their results are appended to the static prompts and reused for subsequent turns.

```python linenums="1" hl_lines="5-11"
from ag2 import Agent, Context

agent = Agent("assistant")

@agent.prompt
async def dynamic_sysprompt(ctx: Context) -> str:
    # Generate prompt dynamically based on the initial event or context
    return (
        "You are a helpful agent. "
        f"The current context is {ctx.variables}."
    )
```

Alternatively, you can pass a callable directly to the `prompt` parameter, or mix static strings and callables in a list:

```python linenums="1" hl_lines="9"
from ag2 import Agent

def get_sysprompt() -> str:
    # Returns a string for the prompt, evaluated at the beginning of the conversation
    return "This is dynamically generated."

agent = Agent(
    "assistant",
    prompt=["Static prompt part.", get_sysprompt]
)
```

### On each conversation turn

While dynamic prompt hooks are evaluated once per conversation, you might need to update the prompt dynamically on each turn. You can do this by mutating the `prompt` list within the `Context` directly between calls to `reply.ask()`.

```python linenums="1" hl_lines="5"
# Initial conversation turn
reply = await agent.ask("Hi, agent!")

# Change the prompt for the next turn
reply.context.prompt = ["You are now a funny agent!"]
await reply.ask("Tell me a joke")
```

You can also completely override the agent's default prompt for a specific run or turn by passing the `prompt` parameter directly to `ask()`:

```python linenums="1" hl_lines="4"
# Overrides the default prompt for this conversation
reply = await agent.ask(
    "Hi!",
    prompt=["Temporary prompt for this run"]
)
```

## Plugins for one invocation

Plugins normally attach when an agent is built. Pass `plugins=` to `Agent.ask()`, `Agent.run()`,
`Agent.resume()`, or a reply's `ask()` / `run()` to add capabilities for one call instead. For
example, build a fresh [`SkillPlugin`](/docs/user-guide/skills) to refresh a long-lived agent's
catalog and tool schemas:

```python linenums="1" hl_lines="8 11 15"
from ag2 import Agent
from ag2.config import OpenAIConfig
from ag2.tools.skills import LocalRuntime, SkillPlugin

runtime = LocalRuntime("./skills")
agent = Agent("assistant", prompt="You are a helpful assistant.", config=OpenAIConfig(model="gpt-5-mini"))

reply = await agent.ask("Help with my project", plugins=[SkillPlugin(runtime)])

# After changing installed skills, invalidate discovery and build a fresh plugin.
runtime.invalidate()
reply = await agent.ask(
    "Use the newly installed skill",
    stream=reply.context.stream,
    plugins=[SkillPlugin(runtime)],
)
```

Invocation plugins contribute prompts, tools, middleware, observers, policies,
context defaults, and HITL. Their rules are:

- Prompt fragments append to the resolved prompt; plugin dynamic hooks run once
  per call. Explicit `prompt=` still replaces the agent's base and dynamic prompts.
- Existing context values beat plugin defaults. Later plugins override earlier
  defaults and same-named tools; explicit `tools=` override plugin tools.
- Policies follow agent policies in one assembler. HITL uses the explicit call
  hook, then the agent hook, then the first plugin hook.
- Scope exit removes the plugin's bound prompt fragments and unreplaced defaults,
  including failure or cancellation. Prompt updates and reassigned defaults
  persist. Pass the plugin again for a continuation; constructor plugins remain
  attached to the agent. Arbitrary side effects of plugin code are not rolled back.

The agent is unchanged, so separate streams can use different plugins concurrently.
Reusing a `SkillPlugin` preserves its snapshot.

!!! warning "Invocation plugins add to constructor plugins"
    They do not replace them. A `SkillPlugin` attached to the agent and another passed to
    `plugins=` render two catalogs in the prompt, so attach a refreshed skill catalog in
    only one place.

!!! note
    Cleanup of a default compares by identity: if code later assigns the identical object
    to the same key, the value is treated as the plugin's own and removed.

## Prompt updates

For continuous and event-driven prompt updates, you can mutate `context.prompt` dynamically from an event subscriber. This allows you to respond to specific events in the stream and adjust the agent's behavior on the fly during an ongoing conversation. See the [Stream](/docs/user-guide/advanced/stream) documentation for more details on this advanced feature.

```python linenums="1" hl_lines="11"
from ag2 import Agent, Context, MemoryStream
from ag2.events import ModelRequest

agent = Agent("assistant", prompt="You are a helpful assistant.")
stream = MemoryStream()

@stream.where(ModelRequest).subscribe()
async def mutate_prompt(event: ModelRequest, context: Context) -> None:
    # Update the prompt dynamically when a ModelRequest is triggered
    if "joke" in event.content.lower():
        context.prompt = ["You are now a comedian."]

await agent.ask("Tell me a joke", stream=stream)
```
